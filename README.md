# DST — Desarrollo Tecnológico

Sitio institucional experimental en español para un estudio independiente de desarrollo tecnológico. HTML, CSS y JavaScript sin dependencias de ejecución.

## Desarrollo

Servir `dist/` con cualquier servidor estático. El sitio usa Canvas 2D, tipografía cinética, navegación accesible, soporte móvil y controles de movimiento reducido. Las fuentes de Google tienen alternativas del sistema.

## Contacto

Los servicios y «Iniciar un proyecto» abren un formulario modal. Envía nombre, email, servicio y mensaje directamente a Web3Forms, con destino a acunaleandro3@gmail.com, sin abrir el correo del visitante. El formulario usa un identificador público diseñado para integrarse en el navegador; no es una credencial privada. El plan gratuito admite 250 consultas/mes. Se valida la respuesta del proveedor antes de mostrar éxito; ante error conserva los campos y evita envíos simultáneos. El aviso de privacidad informa el procesamiento externo. Las barras de desplazamiento comparten el estilo oscuro y verde ácido.

## Publicación

El manifiesto `.openai/hosting.json` identifica el alojamiento de Sites. El repositorio GitHub conserva una copia del código. No se afirma afiliación ni aprobación de Meta u otros proveedores.

Referencias conceptuales de diseño: https://eloyb.design/ y https://www.rejouice.com/ (sin reutilizar código ni recursos).

## Movimiento de portada

La portada alterna cuatro frases cada 5,2 segundos con una transición de bandas glitch. La animación se pausa fuera de pantalla, con menús/diálogos abiertos, en pestañas ocultas o con movimiento reducido. La estela de partículas del mouse se retiró a pedido del usuario. Se conserva el cursor circular original y la rotación de frases.

## Servicios y presentación de la demo

Cuatro áreas: chatbots comerciales, automatización, sistemas/paneles y webs/integraciones. Cada servicio incluye problema, solución y ejemplo. Los encabezados conservan el despliegue nativo; el contacto se abre únicamente desde su botón. Las categorías del formulario coinciden con las nuevas áreas.

La sección #demo muestra una captura real del repositorio independiente dst-chatbot-demo, ampliable en un diálogo. Presenta conversaciones, productos, clientes y borradores ficticios y permite solicitar una demostración. Se identifica expresamente como vista previa: la versión interactiva sigue local, con respuestas no generativas y sin sistemas reales conectados. Esta publicación no despliega el servidor Python de la demo.

## Experiencias explicativas

El selector de problemas recomienda una ruta de servicio y precarga esa categoría en el formulario. Rayos X activa cuatro puntos sobre la captura real, con explicaciones del catálogo, contexto, borrador y control del equipo; no simula un chat en vivo. El control Caos → Sistema revela dos vistas ilustrativas de una solicitud de presupuesto. Las tres interacciones son locales, funcionan con teclado y respetan el control de efectos y movimiento reducido. Los ejemplos incluyen empresas de servicios, turnos y presupuestos, además de comercios con productos.
