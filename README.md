# DST — Desarrollo Tecnológico

Sitio institucional experimental en español para un estudio independiente de desarrollo tecnológico. HTML, CSS y JavaScript sin dependencias de ejecución.

## Desarrollo

Servir `dist/` con cualquier servidor estático. El sitio usa Canvas 2D, tipografía cinética, navegación accesible, soporte móvil y controles de movimiento reducido. Las fuentes de Google tienen alternativas del sistema.

## Contacto

El canal inicial es el formulario público de consultas en GitHub Issues. Se advierte que no se deben publicar datos sensibles. No hay formularios ficticios, analítica ni almacenamiento de consultas en el sitio.

## Publicación

El manifiesto `.openai/hosting.json` identifica el alojamiento de Sites. El repositorio GitHub conserva una copia del código. No se afirma afiliación ni aprobación de Meta u otros proveedores.

Referencias conceptuales de diseño: https://eloyb.design/ y https://www.rejouice.com/ (sin reutilizar código ni recursos).
